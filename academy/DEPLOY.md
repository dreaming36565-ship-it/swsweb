# 배포 안내 — Railway (레일웨이)

> 배포(Deploy, 디플로이) — 만든 프로그램을 인터넷에 올려서 다른 사람도 쓸 수 있게 하는 것.
> Railway — 우리 앱을 24시간 켜 두는 인터넷 서버를 빌려주는 서비스. 월 5달러(약 7천 원), 5달러어치 사용량 포함.

## 한 번만 하는 준비 (사용자가 직접)

가입 · 결제 카드 등록 · 권한 허락은 본인만 할 수 있어요.

1. **가입** — https://railway.com → `Login` → **GitHub 계정으로 로그인** (dreaming36565-ship-it).
2. **요금제** — Hobby 요금제($5/월) 선택, 결제 카드 등록.
   - (권장) Workspace Settings › **Usage** 에서 **사용 한도(Hard limit)를 $10** 로 걸어 두면 그 이상은 절대 청구되지 않아요.
3. **새 프로젝트** — `New Project` → `Deploy from GitHub repo` → **swsweb** 선택
   (처음이면 Railway가 GitHub 저장소를 읽도록 허락하는 화면이 나와요 → swsweb 만 허락).
4. **앱 폴더 지정** — 만들어진 서비스를 누르고 `Settings` › **Root Directory** 에 `academy` 입력.
   (저장소 안에서 앱이 `academy` 폴더에 있어서)
5. **볼륨(저장 공간) 붙이기** — 프로젝트 화면 빈 곳 오른쪽 클릭(또는 서비스 오른쪽 클릭) → **Attach Volume** → Mount path `/data`.
   > 볼륨(Volume) — 서버를 다시 올려도 지워지지 않는 저장 공간. **이게 없으면 고칠 때마다 자료가 사라져요.**
   > 앱이 저절로 이 공간에 DB · 자동 백업을 저장해요(따로 설정할 것 없음).
6. **주소 만들기** — `Settings` › Networking › **Generate Domain** → `○○○.up.railway.app` 주소가 생겨요.
7. 배포가 끝나면(2~5분) 그 주소로 들어가 로그인 화면이 뜨는지 확인.

## 처음 접속 — 이 컴퓨터의 자료 옮기기

인터넷 서버는 처음에 **가짜 이름 데모 자료**로 시작해요. 이 컴퓨터의 진짜 자료로 바꿉니다.

1. **이 컴퓨터**에서 앱을 켜고 안예슬로 로그인 → 설정 › 백업 › **💾 지금 백업 받기** → `academy-backup-날짜.db` 파일이 받아져요.
2. **인터넷 주소**로 들어가 `안예슬` / `1234` 로그인 → 새 비밀번호 정하기.
3. 설정 › 백업 › **📤 백업 올리기** → 1번 파일 선택 → 바꾸기.
4. 다시 로그인 (진짜 자료의 안예슬 비밀번호 = 1234 → 새 비밀번호 정하기).
5. 직원들에게 주소 알려주기 — 각자 **이름 + 1234** 로 로그인하면 새 비밀번호를 정해요.
   (인터넷 서버에서는 1234를 계속 쓸 수 없어요.)

> ⚠ 백업 파일(.db)에는 실제 학생 이름이 들어 있어요. 메신저 · 메일로 보내지 말고 학원 컴퓨터에만 두세요.

## 그 다음부터 (고칠 때)

- 앱을 고치면 → 확인 → **허락 받고** GitHub에 올림(push) → Railway가 **저절로 다시 배포**(2~5분). 자료는 볼륨에 그대로 남아요.
- 실제로 쓰는 자료는 **인터넷 서버**에 있어요. 이 컴퓨터의 자료는 연습용이 돼요.
- **자동 백업**: 하루 한 번, 최근 14개(설정 › 백업에서 받기). 가끔 💾 지금 백업 받기로 학원 컴퓨터에도 한 부 보관하세요.

## 기술 메모 (다음 작업자용)

- 시작 = `npm start` → `scripts/start.mjs`: `PORT` 가 있으면(Railway) `0.0.0.0:PORT`, 없으면 `127.0.0.1:3100`. 항상 `TZ=Asia/Seoul`.
- Node = `package.json` `engines.node` `24.x` (node:sqlite).
- DB 위치 = `ACADEMY_DATA_DIR` → 없으면 `RAILWAY_VOLUME_MOUNT_PATH`(볼륨을 붙이면 Railway가 알려줌) → 없으면 `academy/data`.
  배포 서버인데 볼륨이 없으면 설정 › 백업에 빨간 경고.
- 쿠키 서명 비밀값 = `ACADEMY_SECRET` → 없으면 DB `app_settings.session_secret`(처음에 무작위로 만듦).
- 비밀번호 = scrypt 해시. 예전 평문은 로그인할 때 저절로 바뀐다. 배포 서버에서 1234로 로그인하면 새 비밀번호를 정해야 한다.
- 로그인 10분에 10번 틀리면 잠깐 막힘(이름마다). 쿠키는 배포 서버에서 https 전용.
- 빠른 로그인(데모 계정) 버튼은 배포 서버에서 숨김.
