# 학원 관리 시스템 — 유투엠 분당서현 / 스터디킬러 분당서현

시간표 · SR(알파) 자리배정 · 출결 워크플로우 · 업무 지시를 하나로 묶은 PC(Desktop First) 업무용 웹앱입니다.

## 실행

```bash
npm install --prefix academy
```

```bash
npm run dev --prefix academy
```

→ http://localhost:3100

첫 실행 시 `academy/data/academy.db` 가 자동 생성되고 데모 데이터(직원·반·학생·주간 시간표·SR 배정)가 시드됩니다.

데이터를 초기화하려면 (dev 서버를 끈 상태에서):

```bash
npm run seed --prefix academy
```

> Node.js **24 이상**이 필요합니다. DB로 Node 내장 `node:sqlite` 를 쓰기 때문입니다.

## 핵심 자동화

### 1. 시간표 → SR 자동배정

시간표에 알파 시작/종료와 **SR룸**이 입력되면 해당 요일의 SR 좌석이 즉시 다시 계산됩니다.

- **1순위**: 같은 반 학생을 같은 열(A/B/C/D)에 위아래로 **연속 배치**
- 한 열에 다 앉힐 수 없으면 최소 개수의 열로 나눠 배치
- 그 시간대에 다른 학생이 쓰는 좌석은 절대 배정하지 않음
- 배치 순서: 알파 시작이 이른 순 → 인원이 많은 반 순

구현: `src/lib/sr.ts` `autoAssignSeats()` (순수 함수)

### 2. SR 수동 자리 이동

> **해당 학생의 SR 이용시간 전체 구간 동안 단 한 번도 다른 배정이 없는 좌석만** 이동 가능으로 인정합니다.

예) 이용시간 17:10~18:00 인 학생에게, 17:10엔 비어 있지만 17:30부터 다른 학생이 쓰는 좌석은 **이동 불가**로 표시됩니다.

- 핑크 = 이동 가능 / 진한 네이비 = 선택 학생 / 흰색 = 사용 중 / 회색 = 이동 불가

구현: `src/lib/sr.ts` `movableSeats()`

### 3. 출결 3단계 워크플로우

```
수업 시작 → +2분 → 담당 선생님 "출석체크해주세요."
  → [제출 완료] → 데스크 "출결전화 돌려주세요."
  → [저장 완료] → 담당 선생님 "출결사항 확인해주세요."
  → [확인 완료] → 종료
```

- 출석 / 결석 / **미체크** 3상태. 출석·결석은 동시 체크 불가(다시 누르면 미체크로 복귀)
- 결석 체크 시 결석 사유 필수
- 데스크는 미체크 학생에게 전화 후 지각 사유 + 도착예정시간 기록 (입력하면 자동으로 "지각" 처리)
- 각 단계 전환 시 상대방에게 알림이 쌓이며, 팝업을 닫아도 상단 종 아이콘과 `알림 & 공지`에서 다시 확인 가능
- 팝업은 4초 주기 폴링으로 전 화면 공통 표시 (`AttendanceHost`)
- 알림음: 팝업이 뜨는 순간 + 제출 전까지 1분마다 3초

### 4. 시간표 충돌 감지

페이지 상단 전체 폭 경고 바(연한 레드 + 경고 아이콘)로 표시합니다.

- 같은 강의실 같은 시간 중복 (SR룸은 좌석 단위 공용이므로 제외)
- 같은 선생님 같은 시간 두 수업
- 학생 일정 중복 (수업 + 알파를 모두 학생 점유시간으로 계산)
- SR 좌석 초과 (10분 단위로 동시 알파 인원 > 24석)

구현: `src/lib/conflicts.ts`

## 기술 스택

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4 (디자인 토큰은 `src/app/globals.css` 의 `@theme`)
- SQLite — Node 24 내장 `node:sqlite` (네이티브 빌드 의존성 없음)
- 세션: httpOnly 쿠키 + HMAC 서명
